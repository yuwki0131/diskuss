# diskuss

2つのAIが討論し、オブザーバーAIが勝者と結論を示すローカル Web アプリです。

1. ユーザーが議論テーマを入力し、2人の討論者 (プラトン / アリストテレス) のモデルを選ぶ
2. オブザーバーが両者に対立する立場を設定する (フォームで立場を指定することも可能)
3. 2人がラウンド制で討論する
4. 第2ラウンド以降、オブザーバーが毎ラウンド「議論が煮詰まったか」を判定し、煮詰まるか最大ラウンド数に達したら終了
5. オブザーバーが議論のサマリ・各者の評価・勝者・テーマへの結論を示す

最初の入力以降は、討論完了まで自動で進みます。

## 必要なもの

- Node.js 20 以上 (npm パッケージへの依存はありません)
- ログイン済みのローカル CLI
  - `claude` (Claude Code) — オブザーバーに使うため必須
  - `codex` (Codex CLI) — 任意
  - `copilot` (GitHub Copilot CLI) — 任意

API キーは使わず、すべてローカルの CLI を非対話モードで呼び出します。

## 使い方

```sh
npm start        # または node server.js
```

http://127.0.0.1:3210 を開きます。`PORT` / `HOST` 環境変数で変更できます。

- 討論者のモデルは、インストール済みの CLI ごとに選択できます。
  Codex のモデル一覧は `~/.codex/models_cache.json`、Copilot は `copilot help config` から取得します。
- オブザーバーは Claude Fable 5.1 (`claude-fable-5-1`) 固定です。公平のため、オブザーバーには各発言者のモデル名を伝えません。
- 討論者の名前は「プラトン」(AI1) と「アリストテレス」(AI2) です。`lib/debate.js` の `NAMES` で変更できます (名前は呼び名だけで、人物になりきらせてはいません)。
- 討論者の口調は常体・断定口調です。`lib/debate.js` の `TONE` で変更できます。
- 完了した討論は `transcripts/` に Markdown で保存されます。
- 討論中にページを再読み込みしても、URL の `#<id>` から進行中の討論に復帰します。

## 構成

| ファイル | 役割 |
| --- | --- |
| `server.js` | HTTP サーバー。討論の開始・中断 API と、進行状況の SSE 配信 |
| `lib/providers.js` | claude / codex / copilot CLI の呼び出しとストリーミング出力の解析 |
| `lib/debate.js` | 討論の進行とプロンプト (立場設定・発言・収束判定・最終判定) |
| `public/` | フロントエンド (素の HTML / CSS / JS) |

各 CLI はツールを無効化 (claude: `--tools ""`, codex: `-s read-only`, copilot: `--available-tools=`) し、
空の一時ディレクトリで実行するため、テキスト生成だけを行います。
